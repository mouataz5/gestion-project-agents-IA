# candidate/master_cv/

Place the master CV here (`.docx` preferred, `.pdf` accepted), or upload it through the UI once
Phase 2 is delivered.

Everything in this folder except this README is **git-ignored** because a CV contains personal
contact information. Back it up separately.

The master CV is the single source of truth: tailored CVs may reorder, rephrase and emphasise its
content, but may never add employers, technologies, dates, titles, certifications, education or
metrics that it does not contain.
